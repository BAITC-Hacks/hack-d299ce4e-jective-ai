# Голосовой ввод

В существующем экране создания задачи рядом с описанием и каждым ответом на
уточняющий вопрос доступна кнопка «Ввести голосом».

1. Нажать кнопку и разрешить микрофон в браузере.
2. Продиктовать текст (до двух минут за запись).
3. Нажать «Остановить и распознать» либо дождаться автоматической остановки.
4. Проверить добавленный текст. Ранее введённый текст сохраняется; правки
   во время распознавания также сохраняются. Анализ запускается отдельно.

Для браузерного микрофона нужен HTTPS или localhost. Поддержка формата записи
проверяется через MediaRecorder; доступны WebM, MP4 и Ogg в зависимости от браузера.
При отказе в доступе, отсутствии микрофона или ошибке распознавания можно продолжить
печатать. Неудачную расшифровку можно повторить без новой записи. Отмена и уход со
страницы выключают микрофон и отменяют запрос; поздний результат игнорируется.

После остановки аудио отправляется через `POST /api/ai/task-analysis/transcribe`
в OpenAI Audio Transcriptions. Сервер возвращает `{data: {text}}`. Используется
существующий `OPENAI_API_KEY`; необязательный `OPENAI_TRANSCRIPTION_MODEL` по
умолчанию равен `gpt-4o-mini-transcribe`. Дополнительный ключ не нужен.
Максимум загрузки — 10 МБ, ожидание сервера — 60 секунд. Аудио хранится только
в памяти до завершения/отмены операции (при ошибке — до повтора или ухода);
приложение не сохраняет записи в БД или файлы.

`npm run check` проверяет серверный маршрут, транспорт, состояния записи,
отмену при ожидании разрешения, поздние ответы, ошибки, повтор и автоостановку.
Реальный OpenAI-запрос проверен синтетической русской аудиозаписью через HTTP.
Ручная проверка физического микрофона выполняется в браузере по шагам выше.

API: https://developers.openai.com/api/docs/guides/speech-to-text
